# Frontend (React website)

The website for the Sorsogon Tourism Information System. Setup, checks and deployment are described in the [main README](../README.md).

- Pages and routes: [`src/App.jsx`](src/App.jsx) and [`src/pages/`](src/pages/) (public, tourist, business, admin)
- API calls: [`src/api/`](src/api/)
- Shared components: [`src/components/`](src/components/)
- Run `npm run dev` for local development and `npm run lint` before committing
