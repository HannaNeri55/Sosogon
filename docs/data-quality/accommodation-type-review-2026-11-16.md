# Accommodation type review (2026-11-16)

Stays whose listed type may not match what the place mainly is. **Nothing was changed.** An admin
fixes a stay by editing its categories (Admin → Review Listings / Manage Accommodations).

- Source: the local copy of the database (64 approved stays). The live site may differ slightly;
  check each stay on the live admin before editing it.
- Evidence comes only from each stay's own listing (description and amenities). Nothing here was
  checked with the business, so every row needs a quick confirmation.
- How the planner reads categories now: a stay with **Hotel** only is a hotel; **Hotel + Resort**
  is a "Hotel & Resort"; **Resort** or **Beach Resort** is a resort. A pool or a garden alone never
  makes a hotel a resort.
